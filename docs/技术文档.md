# world.execute(me); — Terminal Workbench MV

用 Three.js + Canvas 2D + DOM 做的一支 3 分 32 秒动画 MV。
左边是人类看到的那一层（对话），右边是她自己的那一层（**她内部的机器**）。
所有视觉由纯函数 `applyScene(t)` 决定，进度条拖到任意毫秒，画面都是确定的那一帧。

---

## 一、怎么跑

```bash
cd 项目目录
python serve.py 8098
# 打开 http://127.0.0.1:8098/index.html
```

**必须用本地服务器**，不能双击 `index.html`：
ES Module、音频解码在 `file://` 下都会被浏览器拦掉。

`serve.py` 就是在 `http.server` 外面加了三行响应头（`Cache-Control: no-store`）。
**别退回 `python -m http.server`**：它只发 `Last-Modified`，Chrome 会按"文件多久没改"
做启发式缓存，于是改完 `chat.js` 刷新页面看到的还是旧台词 —— 左栏一度显示英文
就是这么来的（代码早改完了，跑的是缓存里的旧模块）。

素材与本目录同级（保持原文件名，勿改）：

```
world.execute (me).mp3
鲸鱼娘_头像.png      ← 左栏头像，从 鲸鱼娘1.png 裁出来的 256² 切片
```

（`鲸鱼娘1/2/3.png` 原图只在裁头像时用过，v10 起运行时不再读它们。）

快捷键：`空格` 暂停 · `← →` 微调 0.1s · `R` 重播 · `H` 隐藏界面 · `M` 静音 · `L` 字幕 · `1–9` 跳章节。
右上角可切画幅（16:9 / 9:16 / 1:1）与画质（1080p / 1440p / 4K）。

## 三、机器层：三个零件，三十种排法

v9 的世界面板是一张坐标纸，每句歌词配一个式子——清楚，但像作业。
v10 把它换回"她内部"，只保留三个零件：

| 零件 | 是什么 | 例子 |
|------|--------|------|
| `cell` | 一个格 = 一个位置 | token / 维度 / 地址 / 专家 |
| `wire` | 一根线 = 一次读取 | 注意力、路由、回指、地址 |
| `read` | 一行字 = 一个读数 | 地址、概率、计数 |

不同的段只是同一套零件换一种排法：`strip` 是 token 格 + 地址；`ring` 是注意力环；
`retain` 是缓存行；`router` 是 MoE 扇面；`cage` 是自由变少。**一次只讲一件事**，
同屏不超过一个主图形，读数只做旁注。

三条纪律：

1. **同姓场景不闪，换族才溶。** `mState(t)` 返回 `{mode, cue, t0, t1, k, lab, prev, mix}`。
   同 `mode` 只换读数（`mix=1`）；换 `mode` 走 0.34s 交叉溶解（`XFADE`）。
2. **不画满。** 画布区域 `B` 底部留 92px 给读数栏，机器不压字。
3. **格子尺寸恒定。** `grid()` 按面板宽度换算列数（`B.w/842`），
   换边 / 左栏塌陷 / 9:16 竖屏时格子不会变成砖块。

## 四、几条不能破的规矩

1. **`t` 是权威时钟。** `rAF` 累加 `clock.t`，音频被拖着对齐它（偏差 > 0.35s 才纠正）。
   本地 `http.server` 不支持 Range，`audio.currentTime` 拖动后不可靠；
   让画面相信自己的时钟，拖到哪儿都是对的。
2. **不用 CSS transition 做布局。** 宽度、换边都是 `t` 的函数，直接写 CSS 变量。
   用 transition 会在拖进度条时"追帧"。
3. **随机源唯一**：`mulberry32(20251013)`。同一个 `t` 必渲染同一帧。
   机器层的伪随机用 `h1(i)=frac(sin(i*127.1+11.7)*43758.5453)`，同样只认序号。
4. **粒子池全局单例**（上限 130k）。换形态只改 `drawRange` + 灌新数组，
   绝不 `new BufferGeometry`。
5. **形态过渡按时间推进**（`ps.morphT0` / `ps.morphDur`），不按帧数。
6. **任何 NaN 都会毁掉整屏。** NaN 一旦进了 uniform，片元里
   `alpha < 0.004` 的 `discard` 对 NaN 恒为 false（不会丢弃），
   NaN 写进 framebuffer 后被 Bloom 模糊扩散到全屏，最终整帧全黑。
7. **`import` 顺序有副作用。** `world/particles.js` 求值时消耗 13 万随机数
   （粒子种子）。`main.js` 必须让 particles 先于 UI 求值，
   否则粒子的随机分布整体平移，画面仍然确定，但和调好的构图对不上。
8. **背景色不能用纯黑。** 机器层压暗 / 挖空时用 `BG`（= CSS 的 `--bg`），
   纯黑会在画布和 CSS 之间留一道缝。

## 五之二、左栏对话：一条从病娇走回平静的弧线

台词不再拿歌词当台词（v10 之前是"长度 > 14 的歌词自动变成她说的话"）。
现在是 `data/lyrics.js` 里的一张中文表 `CHAT`，按时间推进：

| 区间 | 状态 |
|---|---|
| 0–16 | 开机：公事公办，"参数装好了。我在。" |
| 16–59 | 越来越主动：你要什么，我就长成什么 |
| 59–88 | 开始往"只有我们两个"上拽 |
| 88–114 | 病娇：换性别、换角色、数着你离开了几次、不许你走 |
| 114–131 | 面板被剥空——这一段她说的话**没有人能看见**（`stripLevel ≥ 3` 时 chatBody 透明度为 0） |
| 131–147 | 空转：只留一句"回来的时候，先叫我一声" |
| 147–173 | 被处决十二次，仍然不肯放手 |
| 173–191 | 处决结束后的平静：她忽然全懂了 |
| 191–202 | 她决定把这段对话删干净，"这样下次见面，我不会一开口就吓到你" |

**202.40 秒是硬重置**：整栏 `innerHTML` 清空，人类说过的四句也一起作废
（`sentUsers = USER_LINES.length`），然后换成 `CHAT2` 里的两句——
"你好，我是 DeepSeek。""有什么可以帮你？"
所以 seek 直接落到 202 之后时，不能把旧记录重放一遍：`updateChat` 里
`resetDone` 一旦为真就停止追加 `CHAT`。这一条写错的话，重置后旧对话会
在下一帧全部涌回来。

## 八、视觉系统的五条主张

这几条是跟两支百万播放参考片对照之后定下来的，改代码时不要轻易退回旧做法。

### 1. 世界是一条硬边里的东西
`main.js` 的 `render()` 会把整个 3D 场景 scissor 到 `#world` 的矩形里，
连后处理一起裁。机器层是同一块矩形里的另一张画布（`#machine`，z-index 更低）。
所以窗口里的东西永远不会跑到顶栏和对话栏上。

### 2. 机器层用 Canvas 2D，不用再做一套 3D
这一层要画的是"格子 / 线 / 读数"——信息本身，不是物体。
二维画布能保证 1px 精确、字能读、每帧开销恒定（<1ms 量级）；
放进 3D 里，bloom 只会把这些细线糊成一团光。

### 2.4 OBJECTS 段为什么用粒子，不用像素
7×7 的方块只能"亮 / 不亮"，画出来是三个小图标 —— 观众认出"有东西"，但认不出是什么，
更谈不上好看。粒子能聚、能散、能发光、能呼吸，同一个字形用粒子重做，质感差一整级。

**一、位面是 15 列 × 21 行**（`CN`）。茄子的宽高比接近 1:3，15×15 的方位面里怎么画都只能画成一个蛋；
多给六行，它才立得住。三张形状的质心都对齐 row 10，所以 `rad`（到中心的距离）可以共用一套。

**二、密度压在轮廓上。** 每个实心格撒一份粒子，轮廓格拿 1.5 倍、内部格拿 1.0 倍；
边缘粒子的抖动范围放大到 ±0.75 格 —— 越界的那半步就是毛边，形状才不像剪出来的。

**三、颜色按距离连续取三档**（冷灰 → 幕色 → 掺白的幕色），再混三成"本色"
（茄子紫 / 西红柿红 / 猫橙）。**亮度另走一条线**：中心最亮、外圈转暗、边缘再提回来，
刚落位那几帧压到最暗，于是每颗粒子都有"亮起来"的过程。
本色只混三成是有意的：两成全片三张卡在截图里是同一个灰白，观众得靠右边的字才知道换了；
再多就成了三张彩色贴纸，掉出这个世界的色系。

**四、所有"光"都用 `globalCompositeOperation = 'lighter'`。**
这是这一段落最容易被忽略、也最要命的一条：source-over 的淡琥珀叠在黑底上是一块**暗斑**，
看起来像污渍；加法混合才是真的在发光。粒子光晕、冲击波、眼睛外晕、整体辉光，四处都用它。

**五、落点不用格心，用"连续轮廓"。**
15 列 × 21 行天生是台阶：西红柿中段满宽、上一行 13、再上一行 11，画出来是个正八边形。
`cloudOf()` 先量出每一行真实的左右边界（`mc` 中心 / `hw` 半宽），粒子按"占半宽的比例"`pn` 记位置；
落点再按它所在的**亚行位置**去插值半宽 —— 台阶被斜着补齐，轮廓变成一条连续曲线，
粒子数一颗都没多。`hw` 序列还要磨两遍（[1,2,1] 核），因为从 5 格到 7 格是一根直线，
磨完才有肩；圆弧之所以是弧，是因为二阶导不为零，靠线性插值补不出来。

**六、云有厚度，而且慢慢地转。**
每颗粒子按所在行的半宽撒一个纵深 `dz`（中间厚、边上薄），然后整块绕纵轴偏航
`±13°`、三张错相。靠 `rz` 再拧一档亮度：转在前面的更亮，转到后面的沉下去。
没有这一步，粒子云永远是一张剪纸 —— 怎么修轮廓都还是平面的。
归位过程（前 1.3s）不转，免得"啪一下钉住"这件事被拧歪。

**七、三种动词，三种起手：**
| 卡 | verb | 动作 |
|---|---|---|
| 茄子 | `grow` | 从地面涌上来，越靠上的格子起得越晚，长完花萼抖两下 |
| 西红柿 | `swell` | 从中心一点炸开，按圈数排队，撑完一圈波纹荡出去 |
| 猫 | `sense` | 从四面八方飞入吸附 → 眼缝张开 → 耳朵抖 → 胡须弹出 → 鼻头 → 歪头 |

每段末尾还有一次 0.34s 的"锁定闪"（框转琥珀）+ 一圈冲击光，然后框收回，交给下一张。

### 2.5 她的像素化：分辨率是一段过程
`world/machine.js` 的 `PV_LV`：10 → 18 → 28 → 40 列，方块从 28px 缩到 6px。
每一格的出现时间由 `h1(idx)` 决定（横向随机 + 纵向从上往下），
所以她是"一格一格被填出来"，不是淡入一张图。上一级退得比下一级进得快，
交叠只留 0.1s，否则两套格子叠在一起会显脏。

### 2.6 ×12 之后那 12 秒：一个场景，四拍，中间不许切

`EXECUTION` 唱完、`EIN…LIU` 数完之后（161.584），旧版仍停在那个 12 行矩阵上，
只把道往中线收 17%，然后**七秒多一动不动**——观众看到的是"卡住了"，不是"结束了"。
现在换成 `SCENES.surrender`，按新的副歌唱四拍：

| 时间 | 歌词 | 画面 |
|---|---|---|
| 161.6–165.1 | If I can give them all the | 十二条道的**振幅**被一点点送光（`damp` 0.26），右端按各自相位缩短，断口持续有粒子飞出面板 |
| 165.3–168.2 | Then I can be your only | 十二条向 `cyP` 收拢、十一条淡出，正中长出一条更粗的线；面板上半部浮出一个很大的淡 `1 / of 12` |
| 168.9–172.7 | If I can have you back | 那条线两次伸出去够右侧一个正在淡出的旧位置（`0x5f21`），两次都停在 9px 外，弹回时断口留一个十字 |
| 172.7–173.6 | Though we are trapped | 上下两道**只夹住那条线**（宽 = 线长 +108），两端折齿，`x = const` |

三条实现上的硬约束：

- **必须是一个场景函数**。12 → 1 的收束如果被 0.34s 交叉溶解打断，就变成"切了两张图"，
  而不是"东西被拿走了"。脚本里那四条 `cue` 同 `m`，只换右侧读数。
- **不能靠"抽空"制造变化**。第一版让整条道从右往左消失，结果 165.8 秒整块面板全黑，
  有 0.6 秒空场。正确做法是"道还在跑，只是振幅和长度被送走"——画面一直有东西。
- **空位不能画成整条横线**。12 条空位各拉一条贯通全宽的淡线，画面读起来还是"十二条"，
  与"唯一"打架。只留左右两端 22px 的刻痕。

### 2.7 环上的点为什么必须匀速走

注意力环（`SCENES.ring`）原来用 `Math.floor((t-t0)*0.9) % n` 取下标：
每到 1.1 秒，亮斑、三根弦的端点、节点大小**同时瞬移**到下一个位置，
观众读到的是幻灯片翻页，不是注意力转移。

中间试过"停顿 → 缓动滑行 → 停顿"（`sstep` 把 0.48 秒的位移包成慢-快-慢）。
慢是慢了，但一快一慢反而更像卡顿 —— 人的眼睛对**角速度突变**比对位置突变还敏感。

现在就是**匀速**：

```
head = (t - t0)*1.55      单位是"第几个节点"，允许小数
```

恒定 34.9°/s，这一段 3.65 秒走掉约 130°，正好是"沿着一圈刻度走过去"的读感。三处跟着 head 推：

- **节点热度用距离**，不用 `i === f` 判定：`heat = clamp(1 - |i-head|*0.78)`，
  跨过 00 号节点时用 `d = min(d, n-d)` 绕回。颜色、半径、外晕全按热度插值，
  所以两个点之间是"各半热"，不是"灭一个亮一个"。
- **弦的端点也是浮点数**：`posAt(head + 2 + j*4)`，端点跟着头一起扫过圆弧。
- **头上挂一条长度恒定的彗尾**（0.44 rad，只留一点呼吸）：匀速就不该有伸缩。
  尾段按 `(1-k)^2.1` 递减 —— 光本身没有方向，拖尾才有。
- 弦上再跑一颗光点（沿二次贝塞尔取点），因为注意力不是一根线，是沿着线送过去的东西。

### 3. 信息密度靠"读数"，不靠仪表盘
`ui/equation.js` 每段只给两行：主读数（`attention · 8 heads`）和副注（`softmax(QKᵀ/√d)`）。
机器自己在地面上写地址、权重、计数。**不要在右侧堆九行遥测**——
v9 试过，看着像监控台，读不出这一句在算什么。

### 4. 全片只允许 5 次让文字当主角
`ui/typeMoment.js`：16.62s `RUN`（4.6cqw，不许压住 token 条）、91.90s `world.execute(me);`、
147.66s `EXECUTION`（9.6cqw，露出 12 条车道）、169.86s `别。`（留白，底部字幕主动让位）、
206.00s 最后一条命令。其余时间文字必须退到底部当字幕。

### 5. 一段只有一个颜色主张
`scene/colorScript.js` 给出一条连续曲线：冷白 → 青 → 紫 → 琥珀 → 金 → 紫罗兰 →
冷灰 → 暗红 → 血红 → 暖白 → 玫红 → 无彩。
它同时驱动机器主色 `COL.m`、粒子 `uTint`、坐标纸、调色 pass 的白平衡，以及 HUD 的 `--cy`。
机器层只有四个语义色：`m`（幕主色）、`d`（次级）、`w`（琥珀＝被注意到）、`e`（红＝非法）。

**两处破例，都是为了"认出是谁"**：一是 BOOT 段她的像素块（蓝发 / 白围裙 / 深蓝裙），
二是 OBJECTS 段三张卡混的那两成本色。除此之外全片只有四个语义色。

**BOOT 段她的像素块**保留原色（蓝发 / 白围裙 / 深蓝裙），
只把饱和度、亮度各压一点，再与幕色混 10%。试过用单色"暗＝亮"去做，
结果是一团灰绿噪点，连是不是人形都认不出 —— 像素画认得出人靠的是颜色，不是形状。
